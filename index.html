TDD Harness FW

GitHub

コンセプト

LLMの非決定的なアウトプットを、複数ゲートによるチェックを強制することで規格化されたアウトプット品質に近づけるためのFW

なぜ作ったか

claude code等のskillは分割されたコンテキストでしかなく、品質や再現性を担保できない。そこで、コーディング業務をワークフロー化し、注入するコンテキストを限定的なものにする。そして、レビュー観点をステップごとに当てることで品質を理想に近づける。そういった機構で、無関心の谷の発生・サボり癖・暴走を排除し、「100点」のコードに近づく仕組みを構築したかった。

特徴

  • 使用するLLMを任意で選択できるprofileシステム
    • codex app-server
    • claude -p
  • 多重・複数種LLMによる観点別レビューゲート
  • LLM動作のログ出力によるオブザーバビリティ
  • ワークフロー自体をLLMに実行させる前提のpilot用スキルの整備
  • （フロントエンド側は不完全）

技術

  • Node.js 22+
  • TypeScript 5.8

Relavo Client + Server

App Store

コンセプト

タグ方式で体験を記録し、スコアベースのランキングによる相対評価で価値観を磨くアプリ。物事の評価は自身の過去との比較によって実現され、その行為の繰り返すことで価値観を明らかにする。

なぜ作ったか

以下を同時に実現するサービスが存在せず、ニッチながらもペインがあると判断したから（ただしターゲットは絞り切れていない）

  • 体験を記録する
  • タグで整理する
  • 固定ではなく柔軟なランキングを生成する

特徴

  • ユーザーの「こうなるだろう」を裏切らない操作感
  • コンセプトを体現したUX
    • スコアは過去の評価を可視化した上で決定できる
  • ゲーミフィケーション要素（記録数に応じたバッジ獲得）で記録作成のモチベーション維持
