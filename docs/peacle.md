# コンセプト
人に関する情報を管理できるアプリ

# なぜ作ったか
同様のコンセプトのアプリはすでに存在しており、アプリ評価からもペインが確実に存在することを確認した。そこで、ユーザーストーリーを整理したところ、差別化の余地があり競合を吸収できると判断した。
