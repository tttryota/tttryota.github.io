# コンセプト
LLMの非決定的なアウトプットを、複数ゲートによるチェックを強制することで規格化されたアウトプット品質に近づけるためのFW

# なぜ作ったか
claude code等のskillは分割されたコンテキストでしかなく、品質や再現性を担保できない。
そこで、コーディング業務をワークフロー化し、注入するコンテキストを限定的なものにする。そして、レビュー観点を整理して強制することで、無関心の谷の発生やサボり癖・暴走を排除し、「100点」のコードに近づく仕組みを構築したかった。

# 特徴
- 使用するLLMを任意で選択できるprofileシステム
  - codex app-server
  - claude -p
- 多重・複数種LLMによる観点別レビューゲート
- LLM動作のログ出力によるオブザーバビリティ
- ワークフロー自体をLLMに実行させる前提のpilot用スキルの整備
- （フロントエンド側は不完全）

# 技術
